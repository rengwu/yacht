# Yacht 0.2.0

Yacht now has a compact native Swift/AppKit interface for monitoring multiple AI subscriptions from the macOS menu bar.

- Track Claude, Codex, Kimi, and Grok accounts in one ordered list.
- Show account labels or provider icons, choose used or remaining percentages, and pick countdown or exact reset times.
- Choose one quota window per account for the menu bar, or hide its figure with Off while keeping it in the dropdown.
- Manage accounts in a compact native table with immediate label editing, drag reordering, and folder discovery.
- Keep stale readings visible, distinguish missing data with a dash, and highlight high usage.
- The Settings window fits its contents; headers and rows have clearer spacing.
- The app now ships as a universal binary for Apple Silicon and Intel, targeting macOS 13 or later.

Existing accounts and thresholds are retained. The new Display controls replace the old template-based interface; legacy configuration values remain stored.

Claude requires `jq` and its optional usage tap. Kimi, Codex, and Grok use profiles already signed in through their respective CLIs. Yacht does not renew Kimi or Grok credentials; run that provider's CLI if the session expires.

The app remains ad-hoc signed and is not notarized. See the README for installation and first-launch instructions.
