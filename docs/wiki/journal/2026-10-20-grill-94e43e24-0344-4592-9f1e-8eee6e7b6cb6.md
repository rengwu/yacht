## Question 34

```text
Round: Reset glyph and colour thresholds
Question: How should the colour thresholds be configured?
Description (Markdown source):
You chose configurable thresholds. The existing app already has one:

| Model | Controls | Behaviour |
| --- | --- | --- |
| One warning threshold, critical derived (existing) | 1 slider, 50–95% used, default 75% | Orange at 75% used; red halfway to 100% (87.5%). The two can never be out of order. |
| Separate warning and critical | 2 sliders | Full control; the app must keep critical above warning |

Thresholds are measured on usage used. When percentages show *remaining*, the Settings label reads in that convention (for example, 'orange at 25% left').
Recommendation: Keep the existing single warning threshold with critical derived: one control, never misordered, already implemented and tested.
Options: One warning threshold, critical derived / Separate warning and critical thresholds
Selected: One warning threshold, critical derived
Notes:
```

## Question 36

```text
Round: Reset glyph and colour thresholds
Question: When a reading is both stale and past a threshold, which treatment wins?
Description (Markdown source):
A stale reading dims. The existing app lets the warning colour override dimming, so staleness never mutes an alarm at the moment it matters most; below the threshold, stale still dims. The dropdown's clock glyph and age show staleness either way.
Recommendation: Warning colour wins over dimming (the existing behaviour).
Options: Warning colour wins over dimming / Dimming always wins
Selected: Warning colour wins over dimming
Notes:
```

## Question 38

```text
Round: Reset glyph and colour thresholds
Question: What colour should a meter be when it is below the warning threshold?
Description (Markdown source):
The mockups use blue. With threshold colours in play, colour can mean 'needs attention' only.

| Option | Effect |
| --- | --- |
| Neutral (text colour) | Orange and red always stand out; calmest at rest |
| System accent colour | Most 'native', but an orange or red accent would look like a warning |
| Fixed blue | Consistent everywhere; ignores the user's accent |
Recommendation: Neutral: colour then appears only when something needs attention, whatever accent colour you use.
Options: Neutral (text colour) / System accent colour / Fixed blue
Selected: Neutral (text colour)
Notes:
```
